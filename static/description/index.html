POS Keyboard Shortcuts

Keyboard-first navigation for Odoo 20 Point of Sale. The module keeps Odoo's native POS workflow and adds safe, configurable shortcuts for Windows/Linux and MacBook keyboards.

Feature overview

POS screenshots

What it adds

  • Windows/Linux shortcuts using Shift plus a letter.
  • MacBook shortcuts using Option plus a letter or Enter.
  • Arrow-key navigation for products, order lines, POS controls and the numpad.
  • Keyboard navigation for customer selection, payment and receipt confirmation screens.
  • A scrollable shortcut reference with row focus and Escape-to-close.
  • Enter activates the focused native POS action.

Configuration

  1. Install the module from Apps.
  2. Open Settings > General Settings.
  3. Enable Keyboard shortcuts once for all POS configurations.
  4. Review the default bindings or restore them from the same settings block.

Designed for native Odoo behavior

The module does not patch Odoo core or replace barcode scanning, offline order storage, payment processing, access rights, taxes, refunds or session accounting. It delegates actions to the standard POS screens and store. Shortcuts are scoped to the active POS tab and can be disabled globally.
